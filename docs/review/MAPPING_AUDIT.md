## How to use

1. After changing aliases, VOCAB_EXTRA, design rules or `tools/gen-labels.js`: `node tools/gen-labels.js && node tools/gen-vocab.js && node tools/audit-mapping.js`.
2. Read new flags; fix real errors in the SOURCE tables, or record a decision in `KEEP` (tools/audit-mapping.js) with the reason.
3. Render suspicious groups: `node tools/audit-sheet.js out.png "title" id label=<label> …` and look at them.
4. `node tests/mapping-audit.js` must pass (no undecided high flags, fixed cases stay fixed, no object id disappears).
