## Size outlook

The live data file `src/curated-data.js` is 50.1 KB for 60 reviewed objects
(~855 bytes each). At that rate all 2301 objects would add ~1.88 MB of text
(0.56 MB gzipped, estimated) to every page load; monster names would add roughly 10% more.
Draft content never enters the build. If coverage grows past a few hundred objects, consider loading the data
lazily per object (proposal only, not implemented).
